## 世界観

人情に熱い黒帯の武道家 NIN-JOE が、師匠の仇 SHOGUN を追って ARAKURE ISLAND に潜入する。島はSHOGUNの罠で、敗北すると無限地獄により始まりへ戻される。

## 根幹システム

- 胆力を支払ってカードを使う
- カードごとに固定コストがある
- 0 -> 1 -> 2 のように昇順かつ連番で使うとコンボ
- コンボ中はカード効果が強化される
- 初期最大胆力は仮で3
- 初期手札は仮で5枚

## 実装済み

- Vite + TypeScript プロトタイプ
- 胆力表示
- 固定コストカード
- 0 -> 1 -> 2 コンボ判定
- コンボ時のダメージ/ブロック強化
- 次コンボ候補表示: Next 1 / Combo 2 / Next 2
- Combo Next カードハイライト
- 敵意図、勝敗、ターン終了
- 間合い表示: 遠 / 中 / 近
- 攻撃カード使用時に近へ踏み込む
- ノックバック付き攻撃カードは確定で一歩間合いを離す
- 敵攻撃は近でのみ命中し、空振り時は敵が一歩詰める
- 敵の構え行動でブロックしつつ一歩詰める
- 敵行動の固定パターン化
- 3戦ランの最小ループ
- 戦闘後の報酬カード選択とスキップ

## カード案

- 突き cost 0
- 正拳 cost 1
- 受け cost 1
- 回し蹴り cost 2
- 黙想 cost 0

## 追加検討中: 間合いシステム

- 間合いは 遠 / 中 / 近
- 敵は基本的に近でしか攻撃できない
- NIN-JOEの攻撃はどの間合いでも当たる
- 攻撃カードを使うと必ず近になる
- 一部攻撃カードには固定でノックバック属性がある
- ノックバックは確定発生
- ガード系は間合いを変えず、近なら敵攻撃を受けてブロックで軽減する
