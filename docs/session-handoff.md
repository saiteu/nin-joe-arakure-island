## 現在の方針

ブラウザで胆力コンボの面白さを検証し、将来的にiOS/Androidへ展開する。最初は正式アセットより、破綻しない仕様と小さい実装を優先する。

Battle 1〜5はゲーム全体の最終決戦ではなく、Act1相当の縦切りとして扱う。Battle 5の `SHOGUNの影` はAct1の締めボスであり、本物のSHOGUNではない、またはあと一歩で逃げられる余地を残す。現在の調整は、将来の次ステージ解禁に耐える基礎ランを作るためのもの。

## 世界観

人情に熱い黒帯の武道家 NIN-JOE が、師匠の仇 SHOGUN を追って ARAKURE ISLAND に潜入する。島はSHOGUNの罠で、敗北すると無限地獄により始まりへ戻される。

## 根幹システム

- 胆力を支払ってカードを使う
- カードごとに固定コストがある
- 0 -> 1 -> 2 のように昇順かつ連番で使うとコンボ
- コンボ中はカード効果が強化される
- 初期最大胆力は仮で3
- 初期手札は仮で5枚

## 追加検討中: 間合いシステム

- 間合いは 遠 / 中 / 近
- 敵は基本的に近でしか攻撃できない
- NIN-JOEの攻撃はどの間合いでも当たる
- 近接攻撃カードを使うと必ず近になる
- 投擲攻撃カードは間合いを変えない
- 一部攻撃カードには固定でノックバック属性がある
- ノックバックは確定発生
- ガード系は間合いを変えず、近なら敵攻撃を受けてブロックで軽減する
