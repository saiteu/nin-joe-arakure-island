# NIN-JOEドット絵生成ブリーフ v0.1

NIN-JOEの仮スプライトをChatGPT画像生成などで作るための指示書。正式素材ではなく、まずは画面に差し込んで手触りを見るための仮素材を想定する。

## 基本方針

- ドット絵
- 横向きサイドビュー
- 見た目は8bit風の制限パレット
- NIN-JOE本体は8〜12色程度、最大16色まで
- 1フレーム64x64px
- 背景なし、透過背景前提
- モーションごとの横並びスプライトシート
- NIN-JOEは忍者ではなく、黒帯の武道家
- カラテの構え、間合い、踏み込みを芯にする
- 投擲、素早いステップ、影の軌跡だけレトロ忍者アクション的に見せる

## 避けるもの

- 既存ゲーム、映画、アニメ、実在人物に似た見た目
- 特定作品名を直接指定したプロンプト
- 黒装束、覆面など、完全な忍者に見える服装
- 高解像度イラスト風、厚塗り、滑らかなグラデーション
- 斜め見下ろし、正面向き、3Dレンダー
- 細すぎてスマホで読めないシルエット
- 武器を常時持っている主人公像

## 共通プロンプト

最初に貼る基本プロンプト。

```txt
オリジナルのゲーム主人公「NIN-JOE」の2Dドット絵スプライトを作成してください。

横向きサイドビューの黒帯武道家。忍者ではなく、カラテを使う人情に熱い男。古い時代劇とB級カラテ活劇を混ぜた雰囲気。低い構え、強い黒帯、読みやすい拳と足のシルエット。投擲や素早いステップもできるが、主役の説得力はカラテの構えと踏み込みから出す。

仕様:
- pixel art
- side view
- transparent background
- 64x64 pixels per frame
- limited 8-bit style palette
- about 8 to 12 colors, maximum 16 colors
- crisp silhouette
- readable on a small mobile screen
- no antialiasing
- no smooth gradients
- no 3D rendering
- no realistic painting
- no existing character resemblance
- no full ninja costume

出力は、同じキャラクターの一貫したデザインで、横一列のスプライトシートにしてください。
```

## モーション別プロンプト

共通プロンプトの最後に、必要なモーションを追加する。

### `idle`

```txt
モーション: idle
フレーム数: 4
内容: 戦闘中の基本構え。低いカラテの構えで、軽く呼吸している。動きは小さく、間合いの緊張感がある。黒帯と拳の位置がはっきり読める。
```

### `walk`

```txt
モーション: walk
フレーム数: 6
内容: 横方向へ進む歩き。通常の歩行ではなく、武道家の摺り足に近い。道中移動にも戦闘中の間合い移動にも使える。上半身の構えは崩しすぎない。
```

### `attack_light`

```txt
モーション: attack_light
フレーム数: 5
内容: 突きまたは正拳。溜め、踏み込み、打撃、戻りが読める短い攻撃。連続技の1段目や2段目に見えるよう、素早く直線的な動きにする。
```

### `attack_heavy`

```txt
モーション: attack_heavy
フレーム数: 7
内容: 回し蹴りまたは胴払いに使える重い攻撃。大きな踏み込み、腰の回転、蹴りまたは低い払い、残心まで見せる。ノックバック攻撃にも使える迫力。
```

### `throw`

```txt
モーション: throw
フレーム数: 6
内容: 投石または手裏剣のような投擲。構え、振りかぶり、投げ、戻り。忍者アクション的な素早さはあるが、NIN-JOE本人は黒帯武道家に見えること。投げた軌跡を小さく入れてもよい。
```

### `guard`

```txt
モーション: guard
フレーム数: 4
内容: 受け、防御。腕を上げて攻撃を受ける硬い構え。衝撃を受けても足腰が崩れない。ガードゲージを使って耐えている感じが出る。
```

### `breath`

```txt
モーション: breath
フレーム数: 6
内容: 黙想、丹田呼吸、集中。深く息を入れて構え直す。派手な魔法ではなく、胸や帯、肩の小さな動きで胆力回復や集中を伝える。
```

### `hit`

```txt
モーション: hit
フレーム数: 3
内容: 被弾。小さくのけぞるが、すぐに構えに戻れそうな反応。大げさに飛ばされない。テンポを止めない短い被弾。
```

### `evade`

```txt
モーション: evade
フレーム数: 5
内容: 後退、回避、間合い回避。素早く一歩下がり、短い影の軌跡が残る。カラテの足運びを保ちつつ、レトロ忍者アクション的な見やすさを足す。
```

### `victory`

```txt
モーション: victory
フレーム数: 5
内容: 戦闘勝利。攻撃後の残心から短い決め姿勢へ移る。派手なポーズより、静かな勝利感と人情黒帯らしい落ち着きを優先する。
```

### `defeat`

```txt
モーション: defeat
フレーム数: 6
内容: 敗北。膝をつく、または崩れ落ちる。コミカルすぎず、次の挑戦につながる悔しさがある。顔や姿勢で完全に諦めていない感じを残す。
```

## 生成の進め方

1. まず `idle` だけ生成して、NIN-JOEの見た目を決める
2. 見た目が良ければ `walk`, `attack_light`, `guard` を生成する
3. 画面に差し込んで、64x64をCSS拡大した時の読みやすさを見る
4. 読みやすければ残りのモーションへ進む
5. 全モーションで服、帯、顔、体格がズレる場合は、`same character design as previous image` を追加して再生成する

## 修正指示テンプレート

似すぎ/忍者寄りになった場合:

```txt
もっと黒帯の武道家に見えるようにしてください。覆面、全身黒装束、忍者らしい服装は避けてください。カラテの構え、道着、黒帯、拳のシルエットを強めてください。
```

高解像度イラストになった場合:

```txt
滑らかなイラストではなく、低解像度のpixel artにしてください。輪郭を硬く、色数を少なく、グラデーションを避けてください。64x64pxのゲームスプライトとして読めるようにしてください。
```

動きが読みにくい場合:

```txt
各フレームのポーズ差をもう少し明確にしてください。小さい画面でも、構え、踏み込み、打撃、戻りが読めるようにしてください。シルエットを優先してください。
```

キャラクターが毎回変わる場合:

```txt
前回と同じNIN-JOEのデザインを維持してください。髪型、道着、黒帯、体格、顔つき、色数を揃え、モーションだけを変えてください。
```
