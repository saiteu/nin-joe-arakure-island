# ローグライク・デッキビルダー 企画書 v0.1

## 現時点の方針

ブラウザで遊べる縦切り版を先に作り、将来的に Capacitor などで iOS / Android に展開する。最初の到達点は「1ランが完走でき、継続プレイと収益化の仮説を検証できる状態」。

## 仮タイトル

`NIN-JOE: ARAKURE ISLAND`

公開前に再検討する仮タイトル。既存作品の `Karateka` を直接タイトルや主人公名に使うと、モチーフというより引用に見えやすいので避ける。

## 世界観

和風、武道、カラテをベースにしたローグライク・デッキビルダー。空気感は古い武道アクションゲーム、時代劇、海外から見た誇張されたニッポン像を混ぜた「まじめにバカをやる」方向。

主人公は人情に熱い黒帯の武道家 `NIN-JOE`。師匠を討った仇である `SHOGUN` を追い、荒くれ者たちが支配する孤島 `ARAKURE ISLAND` に単身潜入する。しかし島そのものが罠であり、NIN-JOEは倒しても倒しても始まりへ戻される無限地獄に囚われる。

行く手には SAMURAI、NINJA、YOKAI、ONI が次々と立ちはだかる。黒帯を風になびかせ、NIN-JOEは地獄の輪廻を断ち切るため、島の奥にいる `SHOGUN` を目指す。

### 主人公の動機

NIN-JOEは復讐のためだけに戦う男ではない。師匠を討たれた怒りはあるが、島に囚われた人々、敵として使い潰される荒くれ者、呪いでYOKAI化した武人たちを見捨てられない。人情に熱いからこそ、SHOGUNの無限地獄を終わらせる。

この動機により、プレイヤーの敗北と再挑戦は「ゲーム都合」ではなく、SHOGUNの罠として世界観に組み込まれる。

### 方向性

- シリアスな復讐譚の形をしているが、固有名詞や演出は少し過剰
- 武道の構え、呼吸、間合い、気合をカード効果にする
- 敵は時代劇、妖怪、武術映画の誇張を混ぜる
- グラフィックはレトロ武道アクション風を参考にするが、キャラクター、構図、UIはオリジナルにする
- ランのやり直しは `SHOGUN` の無限地獄として扱う

### ツッコミと注意

- `KARATEKA` はモチーフとしては強いが、名前や画面構成まで踏襲しすぎると権利面・印象面で危ない
- `ARAKURE ILAND` は味があるが、ゲーム内表記は `ARAKURE ISLAND` に直す
- `NIN-JOE` はかなり良い。人情の `NINJO` と英語名 `JOE` が混ざっていて、B級カラテ活劇の温度に合う
- `NIN-JOE` は `NINJA` と誤認される可能性があるので、主人公紹介では「忍者ではなく人情の男」とわかる文脈を入れる
- `SHOGUN` は仇としてわかりやすい。ただし一般名詞なので、終盤で二つ名や真名を足す余地を残す

## ラン中ステータス: 人情 v0.1

`人情` はNIN-JOEらしさを表すラン中ステータス。戦闘中にHPを直接回復するカードは一旦保留し、回復や救済は戦闘後の道中イベント側に寄せる。

### 役割

- 戦闘外イベントの発生率や内容に影響する
- HPが低い時の救済イベントを少し引き寄せる
- 回復イベントの回復量に影響する
- 攻撃力や防御力の単純な上昇ではなく、ラン全体の粘りや分岐に効く

### 基本値

- 初期値: 1
- 上限: 5
- 下限: 0
- MVPではラン中だけ有効。ランをまたいで永続成長しない
- UIではHP、胆力、間合いの次に小さく表示する

NIN-JOEは最初から人情に熱い男なので、初期値は0ではなく1にする。上限5なら、回復イベントの仮式 `6 + 人情 x 2` でも最大16回復に収まり、戦闘で受けた傷を完全に帳消しにしにくい。

### 上げ方

人情はカードを取るだけで自動的に伸びる値ではなく、ラン中の選択で少しずつ上がる。

- 道中イベントで人助けを選ぶと `+1`
- 一部の人情系カード、またはイベント報酬で `+1`
- 強い報酬や即時回復と引き換えに、人情を上げる選択肢を置く
- 1回のイベントで上がる量は基本 `+1`
- MVPでは戦闘中のカード使用で人情を上げない

### 下がり方

人情は基本的には下げない。ただし将来的に、強欲な選択や非情な選択の代償として下げる余地を残す。

- MVPでは人情低下イベントは入れなくてよい
- 人情を消費して回復する仕組みは入れない
- 人情はリソースではなく、NIN-JOEの評判や徳に近い値として扱う

### 移動イベント v0.1

戦闘勝利後、まずカード報酬を受け取り、その後で次のスポットへ移動する。道中イベントはこの移動中に一定確率で発生する。意図は、戦闘ポイントから次の戦闘ポイントへ向かう道中を視覚的に表現すること。

基本フローは `戦闘勝利 -> カード報酬 -> 次のスポットへ移動 -> イベント発生判定 -> 次の戦闘` とする。HPが少ないほど、また人情が高いほど、回復系イベントが出やすくなる。ただし確定ではない。

- 基本イベント発生率: 25%
- HPが50%未満: 回復系イベントの出現率を上げる
- HPが25%未満: さらに出現率を上げる
- 人情が高いほど、回復量または出現率が少し上がる
- 回復量の仮式: `6 + 人情 x 2`
- 最終戦後は移動イベントを発生させない

MVPではイベントを2種類だけ採用する。あとで追加しやすいよう、イベントは固定分岐のハードコードではなく、`id`、`title`、`body`、`choices`、`weight`、`condition` を持つデータとして扱う。

### 移動画面 v0.1

MVPでは分岐マップではなく、道中演出ありの1本道画面にする。マップノード風の分岐は将来拡張として残し、今はテンポと旅感の両立を優先する。

表示するもの:

- 見出し: `次のスポットへ移動中...`
- 短い道中テキスト
- 進行度: `戦闘 2 / 5` のように現在のラン位置を表示
- HP
- 人情
- 次へ進むボタン

イベントが発生した場合は、同じ移動画面内にイベント本文と選択肢を表示する。イベントが発生しなかった場合は、短い道中テキストだけ見せて次の戦闘へ進む。

文言例:

- 遠くにSHOGUNの城影が見える。NIN-JOEは拳を握り、ぬかるんだ道を進む。
- 竹林の奥で風が鳴る。黒帯が揺れ、次の戦場の気配が近づく。
- 荒くれ島の山道は静かすぎる。静けさの奥で、誰かが助けを待っている。

### MVP採用イベント

#### 茶屋の老婆

荒れた峠の茶屋で、老婆がNIN-JOEを見つける。回復イベントの基本形。

- 握り飯を受け取る: HPを `6 + 人情 x 2` 回復
- 茶屋の薪割りを手伝う: 人情 `+1`
- 急いで先へ進む: 何も起きない

HPが低い時にやや出やすい。純粋な回復と、将来の救済を強める人情上昇の選択にする。

#### 倒れた荒くれ者

さっきまで敵だった荒くれ者が道端で倒れている。SHOGUNに捨て駒にされたらしい。NIN-JOEの「復讐だけではない」動機を見せるイベント。

- 水を分ける: 人情 `+1`
- 手当てする: HPを3失い、人情 `+2`
- 見逃して進む: 何も起きない

MVPでは人情低下はまだ入れない。手当ては痛みを伴う強い人情上昇として扱う。

### ツッコミと注意

- 戦闘中回復は、間合い、ガード、ノックバックの緊張感を弱める可能性があるため、初期実装では入れない
- 戦闘報酬でHP回復を選ばせると、カード獲得の楽しさを削る可能性がある
- 人情を高くしすぎると救済が強くなりすぎるため、火力やデッキ安定度とのトレードオフにする
- 人情は世界観だけでなく、NIN-JOEを他のデッキ構築ゲームと差別化するための軸として扱う
- イベント数が増えたら、回復、人情上昇、カード変化、リスク報酬などのタグを付けて抽選を制御する

## コア体験

- 少ない手札から最善手を選ぶ緊張感
- 戦闘報酬でデッキが変化していく成長感
- 敵の次の行動を読んで、攻撃と防御の優先順位を決める判断
- 1ランごとに異なるカード構成とシナジーを探す楽しさ
- カラテの「攻める、受ける、溜める、見切る」をカードで表現する気持ちよさ

## 根幹システム: 胆力コンボ

このゲームにはコストの概念がある。各カードには技の強度に応じた固定コストが設定されており、そのカードを使う時に、コスト分の胆力を支払う。

- 自キャラには `胆力` がある
- 胆力のデフォルト値は未定
- カードには `0` から `5` の固定コストが設定される
- カードを使う時、そのカードの固定コスト分だけ胆力が減る
- 胆力が許す限り、プレイヤーは手札のカードを使える
- `0, 1, 2` のように、昇順かつ連番でカードを使うとコンボになる
- コンボになったカードは能力が増す
- どの順番からでも次のカードをコンボにできる、ワイルドカード的な特殊カードが存在する
- カードコスト、胆力最大値、現在胆力はゲーム中に上下する場合がある。ただし基本値はカードごとに固定

### このシステムの狙い

カードを使う判断に、コスト順のコンボ構築を重ねる。低コストカードはコンボの起点になりやすく、高コストカードは強いが胆力を大きく消費する。デッキ構築では、強いカードを詰め込むだけでなく、コストの並び、連番の作りやすさ、ワイルドカードの価値が重要になる。

### ツッコミと注意

- `コスト` は使用時に払う値なので意味は通る。世界観に寄せるなら、UI上では `重さ`、`型値`、`気位`、`負荷` など別名も検討する
- コンボ判定が「ドロー順」なのか「使用順」なのかは明確にする必要がある。修正後の案では、カード使用時の順番で判定するのが自然
- ドロー枚数を固定にするのか、何らかの条件で追加ドローできるのか、ターン構造を次に決める
- 0コストカードが強すぎる可能性があるため、0は弱い効果、コンボ起点、または特殊用途に寄せる
- ワイルドカードは便利すぎるとデッキ構築を壊すので、枚数や効果量を絞る

## ターン構造 v0.1

胆力コンボ制では、カードを引くことではなく、カードを使う順番と胆力配分が主な判断になる。

1. ターン開始時、現在胆力を最大胆力まで回復する
2. 山札から規定枚数を引く
3. プレイヤーは手札からカードを選んで使う
4. カード使用時、そのカードの固定コスト分だけ胆力を消費する
5. 使用したカードのコストが直前に使ったカードのコスト + 1 ならコンボ成立
6. コンボ成立中のカードは効果が強化される
7. ワイルドカードは、直前のコストに関係なく次のカードをコンボ扱いにできる
8. 胆力が足りないカードは使えない
9. プレイヤーがターン終了を選ぶと、敵が行動する
10. 未使用の手札は捨て札に送られ、次ターンへ進む

### 仮ルール

- 初期最大胆力は仮で 3 とする
- 初期手札は仮で 5 枚とする
- コンボは使用順で判定する
- 連番は 0 -> 1 -> 2 -> 3 -> 4 -> 5 の昇順のみ
- 同じコストの連打はコンボにならない
- コストを飛ばした場合もコンボにならない
- コンボが途切れたカードは新しい起点になる

### ツッコミと注意

- 初期胆力 3 だと 0, 1, 2 の美しいコンボがちょうど成立する。最初の検証値として扱いやすい
- 高コストカードを強くしすぎると、コンボより単発大技が正解になりやすい
- 低コストカードを弱くしすぎると、コンボ起点としてしか価値がなくなる
- 手札5枚固定だと運の影響が強いので、後で追加ドローやカード保留を検討する
- ワイルドカードはコンボの救済として強いので、初期デッキにはまだ入れず、報酬カードから検証するのがよい

## カードモチーフ v0.1

カードは `KARATE + NIN-JOE` を軸にする。単なる武道技だけでなく、NIN-JOEの人情、師匠の教え、怒り、情けをカード効果に混ぜる。

### カード分類

実装上は `category` と `rarity` をカードに持たせる。カテゴリは報酬プールの偏りを確認するためのラベルで、レアリティ抽選は後で導入する。

- 技: ダメージを与える。正拳、突き、蹴り、踵落としなど
- 投擲: 間合いを変えずにダメージを与える。投石、手裏剣、瓦投げなど。火力は低め
- 受け: ブロック、軽減、カウンター。上段受け、下段払い、見切りなど
- 呼吸: 胆力、ドロー、コンボ補助。黙想、丹田呼吸、残心など
- 人情: NIN-JOEらしい特殊効果。仁義、師匠の教え、涙の正拳、情け無用など
- 奥義: 高コストの大技。コンボ終点として強いが、胆力を大きく使う

### 実装カテゴリ v0.1

- `melee`: 近接攻撃。火力は高めだが間合いが近になる
- `guard`: ブロック。近で攻撃を受けるための防御
- `knockback`: 攻撃後に確定で一歩離す
- `ranged`: 投擲。間合いを変えずに低火力で攻撃する
- `spirit`: 胆力回復や胆力操作
- `combo`: コンボ補助、連番を成立させる価値が高いカード
- `special`: 人情や特殊ルール。MVP後半で増やす

### レアリティ v0.1

- `starter`: 初期デッキ専用
- `common`: 基本報酬。戦闘判断の幅を増やす
- `uncommon`: 少し強い、または役割が尖ったカード
- `rare`: ランの方向性を変えるカード。最初は少数でよい

### カード表示 v0.1

わかりやすさを優先し、カードにはカテゴリとレアリティをバッジ表示する。

- カテゴリは `近接`、`受け`、`ノックバック`、`投擲`、`呼吸`、`コンボ`、`人情` のように日本語で表示する
- レアリティは `starter`、`common`、`uncommon`、`rare` を表示する
- 報酬カードだけでなく、手札にも表示する
- 目的は、効果文を読み切らなくてもカードの役割をぱっと判断できること
- 特に投擲、ノックバック、ブロック崩しの価値を見落としにくくする

### 報酬抽選 v0.1

カード枚数が少ない間は、完全な重み抽選ではなく3枠固定で安定させる。

- 1枠目: `common`
- 2枠目: `common` または `uncommon`
- 3枠目: `common`、`uncommon`、または `rare`
- 同じ報酬カードは同時に提示しない
- 3枚すべて同じ `category` になった場合、最後の1枚だけ別カテゴリ候補から引き直す
- 別カテゴリ候補がない場合は、そのまま提示する
- カード数が増えたら、`common 70% / uncommon 25% / rare 5%` のような重み抽選へ移行する

### コスト帯の役割

- 0: 起点。弱いがコンボを始めやすい。突き、黙想、間合い
- 1: 基本技。攻撃と防御の中核。正拳、受け、踏み込み
- 2: 主力技。コンボ2段目として気持ちよく使う。回し蹴り、踵落とし
- 3: 決め技。初期胆力3では単発か、0->1->2後には使えない重さにする
- 4: 奥義級。胆力強化やコスト軽減がないと扱いにくい
- 5: ロマン枠。強烈だがデッキやレリックで支える必要がある

### 初期デッキ案

- 突き / cost 0 / 敵に3ダメージ。コンボ中なら追加で2ダメージ
- 正拳 / cost 1 / 敵に6ダメージ。コンボ中なら8ダメージ
- 正拳 / cost 1 / 敵に6ダメージ。コンボ中なら8ダメージ
- 受け / cost 1 / ブロック5。コンボ中ならブロック7
- 受け / cost 1 / ブロック5。コンボ中ならブロック7
- 回し蹴り / cost 2 / 敵に12ダメージ。コンボ中なら16ダメージ
- 黙想 / cost 0 / ブロック3。コンボの起点にしやすい

### 報酬カード候補

- 踵落とし / cost 2 / 敵に8ダメージ。コンボ中なら12ダメージ。ノックバック。uncommon
- 投石 / cost 0 / 敵ブロックを2崩す。敵に1ダメージ。間合いを変えない。common
- 手裏剣 / cost 1 / 敵に2ダメージ。コンボ中なら4ダメージ。間合いを変えない。common
- 瓦投げ / cost 1 / 敵ブロックを4崩す。敵に2ダメージ。コンボ中なら4ダメージ。間合いを変えない。uncommon
- 丹田呼吸 / cost 0 / このターンの胆力を1回復。使いすぎると強すぎるので要検証
- 残心 / cost 1 / ブロック4。コンボ中なら6
- 仁義の受け / cost 1 / ブロック6。コンボ中なら8
- 下段払い / cost 0 / ブロック2。コンボ中なら4
- 鉄肩 / cost 1 / 敵に4ダメージ。コンボ中なら6ダメージ。ノックバック。uncommon
- 師匠の教え / cost 2 / ブロック6。胆力を1回復。コンボ中なら2回復
- 涙の正拳 / cost 2 / 敵に8ダメージ。コンボ中なら12ダメージ。common
- 情け無用 / cost 3 / このターン、攻撃カードのコストを1下げる
- 無拍子 / wild / 次に使うカードをコンボ扱いにする

### ツッコミと注意

- 技名だけで固めると普通の武道カードゲームになる。人情カードを必ず混ぜる
- 0コストはコンボ起点として価値が高いので、効果を盛りすぎない
- 初期デッキに2コストを入れすぎると 0->1->2 の成功率が高すぎる可能性がある
- 3以上のカードは序盤から多すぎると手札事故になる。報酬で少しずつ足す
- ワイルドカードはゲームをわかってから触る報酬カードにする
- 近距離戦を主役にするため、投擲は火力ではなくコンボ接続と間合い維持を主な価値にする
- 投擲commonは `投石` と `手裏剣` までに抑え、`瓦投げ` はuncommonにする
- 報酬commonに `涙の正拳` を置き、近接攻撃を取りやすくする
- ノックバックは確定回避に近い価値を持つため、報酬側はuncommon中心かつ近接攻撃より低火力にする
- 投擲の非火力価値として、まずは安全策で敵ブロック崩しだけを足す
- ブロック崩しはそのカード自身の火力を伸ばすより、次の近接攻撃を通すための補助として扱う

## 差別化ポイント v0.1

Slay the Spire型の面白さは参考にしつつ、このゲームでは `胆力コンボ` と `NIN-JOEの人情` を中心に差別化する。

### 主要な差別化

- 使用コスト順コンボ: カードを 0 -> 1 -> 2 のように連番で使うと効果が強化される
- 胆力管理: 毎ターンの胆力内で、単発大技を使うか、連番コンボを組むかを選ぶ
- カラテの型: カードプレイが単なる消費ではなく、技をつなげる型として見える
- 人情カード: 攻撃、防御、ドローだけでなく、師匠、仁義、情け、怒りを効果にする
- 無限地獄: 周回や敗北をSHOGUNの罠として世界観に組み込む

### プレイヤーに感じてほしい判断

- 0コストを今使ってコンボを始めるか、後のために残すか
- 1コスト防御でつなぐか、攻撃でつなぐか
- 2コスト主力技をコンボで強化するか、単発で急いで使うか
- 3以上の大技を入れるために、胆力強化やコスト軽減を集めるか
- ワイルドカードをコンボ救済に使うか、奥義への橋渡しに使うか

### やらないこと

- Slay the Spireのレリック、マップ、敵意図をそのまま名前だけ変えて複製しない
- カード効果を武道技名だけに閉じない
- 高コスト高火力カードだけが正解になるバランスにしない
- ランダム性だけで勝敗が決まる作りにしない

### ツッコミと注意

- 差別化の核は `胆力コンボ`。ここが面白くなければ、他を盛っても弱い
- 人情カードは魅力だが、ギャグに寄りすぎると戦略ゲームとして軽く見える。効果は真面目に強く、名前で味を出す
- 無限地獄設定は便利だが、説明が長いとテンポを壊す。演出は短く、ゲーム内文言で匂わせる

## 間合いシステム v0.1

戦闘には `間合い` の概念を持たせる。間合いは敵との距離を表し、敵の攻撃可否とノックバックの価値を決める。

### 間合い

- 遠: 敵の攻撃は基本的に届かない
- 中: 敵の攻撃は基本的に届かない。近へ移行する前段階
- 近: 敵が攻撃できる距離

名称は仮。`遠・中・近` はわかりやすいが、世界観に寄せるなら `遠間・中間・懐`、`外・中・内`、`一足・二足・三足` なども検討する。

### 基本ルール

- 敵側は基本的に `近` の状態でしか攻撃できない
- NIN-JOEの攻撃カードは、どの間合いでも命中する
- 近接攻撃カードを使うと、必ず間合いが `近` になる
- 投擲攻撃カードは、どの間合いでも命中し、間合いを変えない
- つまり攻撃はダメージを与える一方で、敵の攻撃圏内へ踏み込む行動でもある
- 投擲は踏み込まない代わりに、近接攻撃より火力を低くする
- ブロックだけでなく、間合い管理が防御判断になる

### ノックバック

- 一部の攻撃カードにはノックバック属性が固定で付与される
- ノックバック属性を持つ攻撃カードを使った時、確定でノックバックが発生する
- ノックバックが発生すると、間合いが `近` から `中`、または `中` から `遠` へ離れる
- ノックバックが発生すれば、敵が攻撃予定でも攻撃を無効化できる可能性がある
- ノックバック属性を持つカードは固定。毎回ランダムに付与されるわけではない
- ノックバックは防御行動としても強いため、報酬カードでは火力を近接攻撃より低めに置く
- cheapなノックバックを増やしすぎると近距離戦の緊張感が薄れるため、commonには置かない

### 投擲攻撃

- 投擲攻撃は `ranged` 属性を持つ攻撃カードとして扱う
- 投擲攻撃は間合いを変えずに敵へダメージを与える
- 遠距離から安全に削れる代わりに、ダメージ効率は近接攻撃よりかなり低い
- 投擲攻撃もカード使用順のコンボには参加できる
- 投擲とノックバックは別属性。投擲は「踏み込まない」、ノックバックは「離す」
- 投擲の主な役割は火力ではなく、コンボをつなぐことと、踏み込まずに小さく削ること
- 一部の投擲は敵ブロックを崩す。YOKAI KOBUSHIやSHOGUN結界への小さな対策になる
- MVPでは `投石` と `瓦投げ` にだけブロック崩しを付け、`手裏剣` は純粋なコンボ接続役のままにする

### このシステムの狙い

近接攻撃するほど敵に近づくため、単純な火力押しにリスクが生まれる。ノックバック攻撃は、ダメージを与えながら間合いを外す手段になる。投擲攻撃は、低火力だが踏み込まずにコンボをつなぐ手段になる。これにより、防御の選択肢が `ブロックする`、`攻撃を止める`、`攻撃圏外へ逃がす`、`安全に小さく削る` の複数に分かれる。

### ツッコミと注意

- ノックバックは確定発生にする。確率化はプレイヤーが判断を学びにくくなるので後回し
- 投擲が強すぎると踏み込むリスクが消えるため、火力とコンボ時効果を控えめにする
- 敵の中には遠距離攻撃、突進、ノックバック耐性を持つものを後で追加できる
- NIN-JOEの近接攻撃がどの間合いでも当たる理由は、ゲームテンポ優先として割り切る。演出上は一瞬で踏み込むイメージにする
- `近接攻撃すると近になる` ルールはかなり重要。これがあることで攻撃と防御が同じターン内で緊張する

## MVP戦闘ループ v0.1

最初の実装では、1戦闘が最後まで遊べて、胆力コンボの気持ちよさを検証できることを優先する。

### 戦闘開始

- プレイヤーは最大HP、最大胆力、初期デッキを持つ
- 敵はHP、行動予定、間合い、簡単な行動パターンを持つ
- 山札をシャッフルし、初期手札5枚を引く
- ターン開始時に胆力を最大まで回復する

### プレイヤーターン

- 手札からカードを選んで使う
- カード使用時、固定コスト分の胆力を消費する
- 直前に使ったカードのコスト + 1 ならコンボ成立
- コンボ成立時、カード効果が強化される
- 胆力が足りないカードは使えない
- プレイヤーは任意のタイミングでターン終了できる

### 敵ターン

- 敵は表示された行動予定を実行する
- 敵の攻撃は、間合いが `近` の時だけ成立する
- 間合いが `中` または `遠` なら、基本攻撃は空振りする
- 攻撃、防御、次ターン強攻撃など、最初は少数の行動に絞る
- 敵行動後、次の行動予定を決める

### ターン終了処理

- 未使用の手札は捨て札へ送る
- 使用済みカードも捨て札へ送る
- 山札が足りない場合、捨て札をシャッフルして山札に戻す
- 次ターンの手札を5枚引く

### 勝利時

- 報酬カードを3枚提示する
- プレイヤーは1枚選ぶ、またはスキップできる
- MVPでは次の戦闘へ進むだけでよい

### 敗北時

- SHOGUNの無限地獄により、ランの最初へ戻る
- MVPではリスタートボタンを表示する

### MVPで後回しにするもの

- 複数敵
- ショップ
- 休憩地点
- マップ分岐
- イベント
- レリック相当の常時効果
- 永続アンロック

### ツッコミと注意

- 最初からマップやショップまで作ると、胆力コンボの検証が遅くなる
- まずは1戦闘、次に3連戦、最後に1ランへ広げる
- 報酬カードは早めに必要。デッキが変わらないとローグライク感が出ない
- 敵の意図表示は残す。コンボを攻撃に使うか、防御に使うかの判断に効く
