# 素材リストと調達計画 v0.1

## 方針

Act1の完成度を上げるための素材計画。今すぐ正式素材を全部そろえるのではなく、ゲームの手触りに直結するものから順に差し替える。

- 優先順は `読めること -> 気持ちいいこと -> 世界観が立つこと`
- Act1の5戦ランが固まるまでは、仮素材でもよい
- ただしSEは体感差が大きいので、画像より先に入れてよい
- グラフィックは無料優先。まずCSS/Canvas/ChatGPT下絵で方向確認し、必要なものだけフリー素材や正式生成へ進む
- 有料AIは基本避ける。無料枠、手作業加工、ライセンスが明確なフリー素材を優先する
- 商用化を想定するため、素材ごとにライセンスと出典を記録する
- 既存IPに見えやすい素材、実在ロゴ、人物写真、生成AI由来が不明な素材は避ける

## 無料優先グラフィック手順

1. CSSでスポットごとの色、柄、空気を仮実装する
2. 画面上で見え方を確認し、必要な背景/立ち絵だけを決める
3. ChatGPTで下絵や方向案を作る。正式素材として使う場合は台帳へ記録する
4. 足りないものだけ、Kenney、OpenGameArt、itch.io無料素材、Pixabayなどで探す
5. 有料素材や有料AIは、Act1の絵柄が固まり、無料手段で足りない場合だけ検討する

## キャラクター素材

### グラフィック方向

キャラクター/敵はドット絵方向で進める。レジェンドゲーム `KARATEKA` は参照元として強いが、既存IPに見えないよう、直接的な画面構成、キャラクター形状、モーションのコピーは避ける。

方向性は `硬派カラテ横スクロール型` と `レトロアーケード忍者アクション型` の合成にする。NIN-JOEの芯はカラテの構え、間合い、踏み込みに置き、投擲、素早いステップ、影の表現で忍者アクション的な見やすさを足す。

取り入れるもの:

- 横視点の間合いの緊張感
- 構え、踏み込み、受けの読みやすさ
- 少ないアニメーション枚数でも成立する武道の所作
- レトロ武道アクションの静かな迫力
- 投擲や回避が一目で読めるシルエット
- 影、布、軌跡で見せるレトロアーケード的な素早さ

役割分担:

- カラテ要素: idle, step, strike, guard, breath の基本姿勢
- 忍者アクション要素: throw, quick step, shadow trail, hit spark の演出
- NIN-JOE本体: 忍者ではなく、黒帯の武道家として見せる
- 敵/演出: 忍者、妖怪、影の要素を強めてもよい

避けるもの:

- `KARATEKA` の主人公/敵に見える服装やシルエット
- 既存画面の構図そのものの再現
- 似すぎたモーションのトレース
- 高解像度イラスト前提で、後からアニメーションしづらい絵
- NIN-JOE本人が完全な忍者に見える黒装束や覆面
- カラテの間合いより、常時ダッシュ/飛び道具が主役に見える表現

初期の作り方:

- まずは低解像度ドット絵の横向き立ち絵にする
- NIN-JOEは `idle`, `step`, `strike`, `guard`, `breath`, `throw`, `hit` の最小差分から検討する
- 敵は最初は `idle`, `attack`, `hit` 程度でよい
- 1体あたりのフレーム数を増やしすぎず、アニメーションしやすさを優先する
- ChatGPT画像生成を使う場合も、最終的にはドット絵化/減色/手直ししやすい構図にする

### NIN-JOE

必要な最小セット:

- 通常立ち: 人情黒帯の基本姿勢
- 近接攻撃: 突き/正拳/回し蹴りに使い回せる踏み込み
- 受け/呼吸: ガード、黙想、丹田呼吸に使える構え

正式化する時の方向:

- 忍者ではなく、黒帯の武道家に見えること
- 顔や体格で「人情に熱い男」が伝わること
- 投擲や素早い踏み込みはできるが、主役の説得力はカラテの構えから出すこと
- B級カラテ活劇の少し過剰なポーズ
- スマホで縮小しても黒帯と構えが読めること

調達方法:

- 初期: 現在のCSSシルエットを拡張
- 中期: オリジナルの簡易イラストを作成、または生成画像を下絵にして手直し
- 正式: 外注または自作で統一タッチにする

### 敵

必要な最小セット:

- ARAKURE SAMURAI: 基本敵。竹刀、荒くれ、海辺の門番
- NINJA MABUSHI: 細身、素早い、投擲
- YOKAI KOBUSHI: 大きい拳、妖気、硬い防御
- ONI BANCHOU: 中ボス。赤い番長旗、圧、ラリアット
- SHOGUNの影: 紙片、影武者、城門の分身

調達方法:

- 初期: 既存CSSシルエットを維持し、スポット背景で差を出す
- 中期: 敵ごとに1枚ずつ立ち絵を追加
- 正式: Act2以降の敵方針が見えてから統一発注

| --- | --- | --- |

| `melee_hit` | 突き、正拳、返し突き | 短い打撃音。痛すぎない |
| `kick_heavy` | 回し蹴り、踵落とし | 少し低い打撃音 |

| `combo` | コンボ成立 | 派手すぎない金属/気合の上昇音 |
| `enemy_attack` | 敵攻撃 | 低めの打撃/斬撃 |
| `knockback` | ノックバック | 押し戻し、後退、風圧 |

- 初期: フリーSEを短く加工して使用

- 正式: 音量、長さ、ピークを統一し、モバイルで耳に痛くないよう調整

## 調達先候補

公式ページ確認日: 2026-05-06。

### 無料/低コスト

- Kenney: CC0中心。UI、効果音、汎用素材の仮置きに強い。公式FAQでは商用利用可、クレジット不要とされている
- OpenGameArt: 商用利用可能な素材も多いが、素材ごとにライセンス確認が必要。クレジット指定も素材ごとに見る
- Game-icons.net: CC BY 3.0。カードカテゴリや状態アイコン向け。クレジット必須
- Freesound: CC0、CC BY、CC BY-NCが混在。商用予定ならCC0かCC BYに絞り、CC BYはクレジットを残す
- Pixabay: 画像/音楽/SEに使えるが、単体再配布や商標/人物/権利には注意
- Sonniss GDC Game Audio Bundle: 商用利用可能なSE調達候補。容量が大きいので必要音だけ選ぶ。AI/ML学習用途は禁止されている

### 有料

- itch.ioの有料アセット: 価格帯が広く探しやすいが、ライセンス表記が作者ごとに異なる。購入前に必ず確認
- Unity Asset Store / Unreal Marketplace系: 音素材や環境素材は便利だが、Web/Viteプロジェクトで使える形式か確認
- 外注: キャラクター立ち絵、キービジュアル、BGMなど、ゲーム固有性が強い素材に向く

### 自作/生成

- 自作録音: SEに向く。紙、布、木、息、足音はNIN-JOEの雰囲気と相性がよい
- AI生成画像: 下絵や方向確認には便利。ただし正式素材に使う場合は、利用規約、商用利用、再現性、加筆方針を確認する
- AI生成SE: ElevenLabs Sound EffectsやSFXforgeなどが候補。商用利用はプランやサービス規約に依存するため、生成日とプランを `docs/asset-credits.md` に残す
- AI生成BGM: 使う場合は短い仮ループや方向確認に留めるのが安全。正式採用するなら、有料プランの商用利用条件、配信可否、著作権上の不確実性を個別確認する
- CSS/Canvas: 背景トーン、紙片、光、影、揺れなどはコードで作れる。今の段階ではかなり有効

### ChatGPT画像生成の使い方

ChatGPTで画像生成できる場合は、まず正式素材ではなく「方向を決めるための仮素材」として使う。

向いている用途:

- NIN-JOEの立ち絵方向確認
- 敵5体のシルエット案
- Act1スポット背景のラフ
- カード背景のムード案
- キービジュアルの構図検討

使う時の注意:

- 既存IP名、実在俳優名、既存ゲーム名をプロンプトに入れない
- `Karateka風` のような既存作品直指定は避け、`レトロ武道アクションの空気` 程度に言い換える
- 採用する場合は、生成日、サービス、プロンプト要約、加工内容を `docs/asset-credits.md` に記録する
- 正式版は、生成画像をそのまま使うより、加筆/統一タッチ化する方が安全

NIN-JOE向けプロンプトの方向例:

```txt
人情に熱い黒帯の武道家。忍者ではなく、古い時代劇とB級カラテ映画を混ぜたオリジナル主人公。力強い正拳突きの構え。シルエットで黒帯が読める。ゲーム用立ち絵、全身、背景なし。
```

### SE生成の使い方

SEは生成サービスと自作録音の相性がよい。最初は短い音だけ作る。

優先する生成音:

- `card_select`: 0.1〜0.2秒
- `melee_hit`: 0.15〜0.35秒
- `guard`: 0.2〜0.5秒
- `throw`: 0.2〜0.4秒
- `block_break`: 0.2〜0.5秒
- `breath`: 0.4〜0.8秒
- `combo`: 0.5〜0.9秒

避けるもの:

- 1秒以上の長すぎるカードSE
- 攻撃のたびに耳に刺さる高音
- 実在作品っぽい必殺技音
- ライセンス条件が曖昧な無料生成音

### BGMの方針

BGMはSEより後でよい。今は戦闘テンポとUI音の手触りを優先する。

おすすめ順:

1. まずBGMなしでSEを入れる
2. 次に `travel` だけ環境音ループを入れる
3. 通常戦闘用の短い低音ループを仮で入れる
4. ONI/SHOGUNだけ差し替えが必要か確認する
5. 正式化するなら外注、自作、または商用条件が明確な音源にする

生成BGMを使う場合の注意:

- Suno、Udioなどの歌もの生成は、商用権利や配信可否が変わりやすいので慎重に扱う
- 歌詞入りやボーカル入りは避け、まずインスト/短尺ループにする
- 有料プランで生成したか、商用利用可か、配信/ゲーム組み込み可かを記録する
- YouTubeやストア公開を想定するなら、Content IDや類似曲リスクも見る

## ライセンス記録ルール

素材を入れる時は `docs/asset-credits.md` に最低限以下を記録する。

| 項目 | 内容 |
| --- | --- |
| ファイル | `public/assets/...` のパス |
| 用途 | SE、BGM、キャラクター、背景など |
| 作者 | 作者名または配布元 |
| 配布元URL | ダウンロードページ |
| ライセンス | CC0、CC BY、独自ライセンスなど |
| 表記要否 | クレジットが必要か |
| 加工 | トリミング、音量調整、色変更など |
| 使用可否メモ | 商用可、再配布不可、AI学習不可など |

避けるもの:

- CC BY-NCなど、商用利用不可の素材
- ライセンスが書かれていない素材
- 実在企業ロゴや商標が入った素材
- 既存ゲーム/アニメ/映画に似すぎる素材
- 生成AI使用の有無や権利が不透明な有料素材
